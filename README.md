# Pogo-Trainer

A Rocket League plugin that helps players practice their pogo shots and pogo recoveries.

There are various settings the user can change to help practice specific aspects, such as adding random angular velocity to the ball and car to make getting into position harder, or making the ball spawn offset from the car so that the player must hit a pogo that is not a straight shot to the net.

Everything needed to operate the plugin is in the tab for this plugin in the bakkesmod plugins tab.
